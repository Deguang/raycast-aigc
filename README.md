# CogView Generator

Raycast extension for generating images and videos using ZhipuAI's GLM-4 and CogView models.

## Features

- **Text to Image**: Generate high-quality images using `CogView-3-Flash` and other models.
  - Support for multiple aspect ratios (1:1, 16:9, 9:16, etc.)
- **Text to Video**: Generate videos using `CogVideoX`.
  - Native in-window video preview.
  - Automatic background downloading.
- **History**: View, regenerate, and manage your past creations.
  - Separate "Preview" and "Details" views.
  - Copy prompt/image/video URL easily.

## Configuration

This extension requires a ZhipuAI API Key.

1.  Get your API Key from [BigModel Open Platform](https://open.bigmodel.cn/).
2.  Install this extension.
3.  Go to **Raycast Preferences** -> **Extensions** -> **CogView Generator**.
4.  Paste your API Key.

## Commands

- **Generate Image**: Create new images from text.
- **Generate Video**: Create new videos from text.
- **Generation History**: Browse your generation library.
